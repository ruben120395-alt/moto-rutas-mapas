# Moto Rutas · mapas

Archivos de mapas sin conexión para la app Moto Rutas, generados a partir de
[OpenStreetMap](https://www.openstreetmap.org/copyright) (© colaboradores de OpenStreetMap, licencia ODbL)
con [Planetiler](https://github.com/onthegomap/planetiler) y el esquema OpenMapTiles.
Estilos, fuentes e iconos de [OpenFreeMap](https://openfreemap.org).

Los archivos están en **Releases → mapas**. Para generar o actualizar un mapa:
pestaña **Actions → Generar mapa → Run workflow**.
